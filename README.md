# SteamLibraryRec

In progress application that allows easy comparison of steam libraries between users

Requirements: 
    1) Create a Steam web api account: https://steamcommunity.com/dev 
    2) All Steam users must have public accounts

Current Features:
    1) Get all games owned by a Steam user
    2) Get all games shared by an indefinite number of Steam users
    3) Get genres of a game on Steam by its app id
